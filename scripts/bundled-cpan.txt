# CPAN distributions with XS code that are linked into perl.wasm.
#
# These are XS distributions that a large number of other CPAN distributions
# depend on. Their C code reaches into interpreter structures directly, so it
# is compiled here against the real perl headers, exactly like the core's own
# XS extensions, and their modules ship in the stdlib.
#
# One distribution per line:
#   <extension name> <archive path under CPAN authors/id> <sha256 of the archive>
# The extension name is what goes into static_ext; the distribution is unpacked
# into perl5/cpan/<name with "/" replaced by "-">. Each XS module needs a
# matching boot_* registration in perl.cc's xs_init. A trailing "core-makefile"
# is explained in fetch-bundled-cpan.py.
